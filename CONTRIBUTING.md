# Contributing

The most useful contributions are corrections backed by a specific cabinet model, motherboard/CPU combination, software version or captured configuration.

Please separate measured facts, owner reports and assumptions. State whether a result was observed in BIOS, Linux, Windows, the frontend or an emulator. For controls, distinguish physical button position, Linux event code, Windows remapping and emulator binding.

Do not submit ROMs, BIOS images, emulator/game executables, Windows system files, activation keys, passwords, personal account data or full registry dumps. Review configuration files for private addresses and credentials before contributing. Preserve source/version information when possible.

Documentation should remain focused on the existing setup. Proposed migrations and automation should be clearly identified as separate future work, not described as an observed property of the cabinet.

Questions, interest in future work and corrections can be sent through [the maintainer's contact page](https://sebastien.bio.link/). No public email address has been assumed.
